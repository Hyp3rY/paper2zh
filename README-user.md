====================================
  PDF 转中文（英文论文 → 中文 Markdown）
  非官方项目，基于开源项目 MinerU
====================================

怎么用（只有三步）
------------------
1. 解压到一个你找得到的位置（例如 D:\Tools\paper2zh；路径带中文也能用，会自动兼容，但纯英文最省事）
2. 双击「1-开始安装.cmd」，等它跑完（第一次约 5–10 分钟，要下载约 3 GB；
   它会自动装进 AI 工具并自检，看到「全部就绪」就好了）

之后怎么用
----------
打开你的 AI 工具（Claude Code / Codex / Cursor / Gemini CLI / DSH 都行），
在对话框里输入 /paper2zh，再接一句要求：

    /paper2zh 把 D:\论文\xxx.pdf 翻成中文

输入 /paper2zh 能确认这次调用的是本技能；如果你的客户端不支持斜杠，直接说
「用 paper2zh 把 … 翻成中文」也行。AI 开始回复「正在本地解析」就说明技能已加载。

它会自己解析、翻译、检查。你不用敲命令。

结果在哪
--------
在 PDF 旁边的「翻译结果」文件夹里：
    中文版.md         中文版
    zh.docx       中文版 Word（对 AI 说「顺便导出 Word」时才有）
    bilingual.docx 中英对照 Word
    中英对照.md  中英对照版
    images\       图片
    先读我.txt    这一份的说明，以及哪几段可能有问题

出问题怎么办
------------
重新双击「1-开始安装.cmd」，它会跳过已完成的部分，把缺的东西补上并重新检查。
最常见的两种：
  - 报「模型缺失」→ 重新双击「1-开始安装.cmd」，会断点续传
  - 窗口一闪就没     → 杀毒软件拦了，把整个文件夹加白名单

断网环境
--------
请找维护者要「完整离线包」，直接解压覆盖即可，不需要联网。

已知限制
--------
- 扫描版 PDF 也能翻（本地 OCR），但清晰度决定识别质量，建议翻完核对前两页
- 没有独立显卡的电脑会慢 3–5 倍
- 公式、图片、表格会原位保留；参考文献不翻译
- 这是个人开源项目，不提供任何担保
